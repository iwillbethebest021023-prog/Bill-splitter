# 環遊世界分賬小助手

這是一個可直接部署到 GitHub Pages 的純靜態網頁工具。網站首頁會開啟 `outputs/bill-splitter.html`。

## 發布到 GitHub Pages

1. 在 GitHub 建立一個新的公開儲存庫，例如 `world-trip-splitter`。
2. 將本資料夾的所有檔案上傳到該儲存庫的預設分支。
3. 在儲存庫選擇 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. 選擇預設分支及資料夾 **/(root)**，然後按 **Save**。
6. GitHub 會提供一個網址，例如：`https://你的帳戶名稱.github.io/world-trip-splitter/`。

這個版本為純前端工具；任何人可透過網址使用，但資料不會與其他使用者同步。
